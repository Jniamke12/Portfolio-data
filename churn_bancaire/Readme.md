# **Analyse Prédictive du Churn Bancaire + Dashboard Interactif**
 **Objectif**

Identifier les clients présentant un risque élevé de quitter leur banque afin d’optimiser les actions de fidélisation et réduire les pertes de revenus.

**Fonctionnalités**

Analyse exploratoire du churn (pays, produits, statut actif)

3 modèles ML comparés : Logistic Regression, Decision Tree, Random Forest

Évaluation complète : Accuracy, Precision, Recall, F1-Score, ROC-AUC

Dashboard R Shiny pour visualiser les KPI et les insights en temps réel

**Résultats Clés
Statistiques**

10 000 clients

43,05 % taux de churn

7 946 clients actifs

48,3 ans âge moyen

**Insights Décisifs**

1️⃣ Taux de churn inquiétant → nécessité d’actions ciblées
2️⃣ L’Allemagne présente le risque le plus élevé
3️⃣ Plus un client possède de produits → plus il reste fidèle
